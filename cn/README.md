# Styio 使用说明

Styio 是一门采用符号语法表达数据流的通用编程语言。这里从可运行程序出发，解释写法、组合方式与边界；流处理和资源拓扑是能力的一部分，不限制它只能用于一个领域。

本版编译器基线: [`fd3b3e2d9a90`](https://github.com/Unka-Malloc/styio-nightly/tree/fd3b3e2d9a900fa58bc70641a42885c991650210). 这是下游 nightly 源码版本，不是发布承诺。

1. [当前语法与第一个程序](current-language.md)
2. [Cookbook：连续 guard、输入转换、推导与复用](cookbook/chaining-and-composition.md)
3. [历史设计资料（不作为当前语法教程）](legacy-index.md)

从第一个程序开始，再比较 cookbook 中的可运行写法。每个例子都说明预期结果、适合的场景和容易误用的边界。

[版本、示例来源与贡献](contributing.md)是更新本书时使用的附录，不是学习语言的前置知识。
