# Styio user guide

Styio is a general-purpose programming language with symbolic syntax for expressing data flow. This guide starts with concrete programs, composition patterns, and their limits. Streams and resource topology are part of its capabilities, not a restriction to one application domain.

Compiler baseline: [`fd3b3e2d9a90`](https://github.com/Unka-Malloc/styio-nightly/tree/fd3b3e2d9a900fa58bc70641a42885c991650210). This is a downstream nightly source revision, not a published-release claim.

1. [Current forms and your first program](current-language.md)
2. [Cookbook: guard chains, input transformation, inference and reuse](cookbook/chaining-and-composition.md)
3. [Historical design notes (not current syntax guidance)](legacy-index.md)

Start with your first program, then compare the runnable cookbook examples. Each explains its expected result, when the form is useful, and common mistakes.

[Version, sources, and contributions](contributing.md) is an appendix for updating this book, not a prerequisite for learning the language.
